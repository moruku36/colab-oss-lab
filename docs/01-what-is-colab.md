# Colab とは何か

## 一言で

Google Colab（正式には Colaboratory）は、**ブラウザだけで使える、借り物のパソコン**です。

自分のPCに難しいソフトを入れなくても、Pythonという言語を実行できます。  
画面は「ノートブック」と呼ばれ、文章とプログラムが同じページに並びます。

アクセス先: [https://colab.research.google.com](https://colab.research.google.com)

## 何が嬉しいのか

普通、AIを動かすには次のものが要ります。

- 高いグラフィックボード（GPU）
- 専用のソフト一式
- 環境が壊れたときの修復

Colabでは、これらをGoogle側の機械で借りられます。  
自分のPCが弱くても、ブラウザさえあれば実験できます。

## ノートブックの見方

ノートブックは、ブロック（セル）が縦に並んだ文書です。

- **テキストセル** … 説明文
- **コードセル** … 実行するプログラム。左の ▶ か `Shift + Enter` で動く

上から順に実行するのが基本です。途中のセルを飛ばすと、あとでエラーになりやすいです。

## セルとターミナルは別物

Colabには「Terminal」（黒い画面）もあります。

| 場所 | 書くもの | 例 |
|---|---|---|
| コードセル | Python。先頭の `!` で一時的にコマンドも可 | `gpu_info = !nvidia-smi` |
| Terminal | 普通のLinuxコマンド | `nvidia-smi` |

セル用のコードをTerminalに貼ると失敗します。  
逆も同じです。迷ったら、白い（灰色の）コードセルを使ってください。

## 大事な制限

Colabのパソコンは、自分の机の上のPCではありません。

- 一定時間で接続が切れる
- 切れると、その機械の中のファイルは消える
- 次に開くと、別の機械に当たることがある
- 保存されるのは、Google Drive上のノート本体（説明とコード）

「動かした結果の大きなファイル」は、自分で Drive などに移さないと残らない、と覚えてください。

## 無料と有料

Colab自体は無料でも使えます。  
ただし無料は、強い計算機が当たりにくく、切れやすいです。
