# 量子化とは何か

## 一言で

量子化は、モデルの中身を圧縮して、狭い机にも載せる技術です。

写真をJPEGにするイメージに近いです。  
小さくなります。よく見ると差はあります。日常の会話では、4bit程度なら気づきにくいことが多いです。

## なぜ必要か

元のモデルは、だいたい16bitという細かい数字の束です。  
8Bモデルでも、圧縮しないと16GB前後になります。L4の机は約22.5GBなので、会話用の予備を入れるとすぐ一杯です。

4bitにすると、だいたい4分の1近くまで小さくできます。  
そのおかげで、14BクラスもL4で現実的になります。

## よく出る名前（今覚える分だけ）

| 名前 | 何のため |
|---|---|
| 4bit / NF4 / Unsloth 4bit | Colabで動かして、追加学習するとき |
| AWQ | GPUで速く会話したいとき |
| GGUF（Q4_K_M など） | 家のPCに持ち帰るとき |
| FP8 / Q8 | ほぼ圧縮なしに近い。品質重視。大きいモデルは載りにくい |
| NVFP4 | 新しい圧縮。今のL4では後回しでよい |

同じ「4bit」でも中身は違います。  
学習用の4bitを、そのまま本番サーバー用だと思わない方がよいです。

## ビットが小さいほど何が起きるか

- 8bit付近 … ほとんど劣化しない
- 4bit … 今の標準。普通の会話は大丈夫なことが多い
- 3bit以下 … 日本語や、長い推理が崩れやすい

小さいモデルを無理に2bitにするより、一段小さいモデルを良い4bitで動かす方が安定します。

## 今の方針

1. Colabの上では 4bit（Unsloth など）で試す
2. 気に入ったら GGUF にして家へ持っていく
3. 「速さだけ欲しい」になったら AWQ を検討する

最初から全部を使い分ける必要はありません。  
「圧縮しないと机に載らないことがある」と分かっていれば十分です。
