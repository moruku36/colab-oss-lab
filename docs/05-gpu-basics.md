# GPU と L4 / A100 の違い

## GPU は何か

CPUは、いろいろな仕事を順番にこなす総合職です。  
GPUは、同じ計算を大量に同時にやる装置です。AIの計算はこちらが得意です。

Colabで「ランタイムのタイプを変更」から選ぶ T4 / L4 / A100 は、どれもGPUです。  
強さと机の広さ（VRAM）と、回数券の減り方が違います。

## VRAM は作業机

モデルを動かすときは、中身をGPUの机の上に広げます。  
机に載らなければ動きません。エラー名はよく `CUDA out of memory` や OOM です。

| 名前 | 机の広さの目安 | 今の契約 |
|---|---|---|
| T4 | 約16GB | 選べる。節約向き |
| **L4** | 約22.5GB | **普段はこれ** |
| A100 | 約40GB | 必要なときだけ |
| H100 / G4 | さらに広い | 今は選べない |

A100に変えても、モデルそのものが賢くなるわけではありません。  
同じモデルなら、返事の中身はほぼ同じで、待ち時間と回数券だけが変わります。

## なぜ普段は L4 なのか

月の枠は回数券です。強い機械ほど、同じ1時間でも券が早く減ります。

たとえ:

- T4 … 4人掛けのテーブル。安い
- L4 … 6人掛け。普段の食事は足りる
- A100 … 10人掛けの宴会場。レンタル料が高い
- H100 … もっと広い。今の会員証では入れない

友達4人のランチに宴会場を借りないのと同じで、  
8B〜14Bを試すだけなら L4 で足ります。

A100を使うのは、L4で机が足りなくなったときです。

## 画面での選び方

1. ノートを開く
2. メニュー「ランタイム」→「ランタイムのタイプを変更」
3. Hardware accelerator で **L4 GPU** を選ぶ
4. High-RAM があればONでもよい
5. Runtime version は Latest のまま
6. Save

当たったかの確認は、Terminal なら:

```bash
nvidia-smi
```

コードセルなら:

```python
import torch
print(torch.cuda.get_device_name(0))
print(round(torch.cuda.get_device_properties(0).total_memory / 1024**3, 1), "GB")
```

`NVIDIA L4` と出れば成功です。

## 「一番いいモデル」の正しい探し方

順番はこうです。

1. 新しくて評判のよいOSSモデルを選ぶ
2. 4bitに圧縮して L4 に載るか見る
3. 載らなければ A100 を試す
4. それでもダメなら、一段小さいモデルにする

GPUを上げることより、載るサイズの良いモデルを選ぶ方が効果があります。
