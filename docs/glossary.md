# ことばの一覧

アルファベット順ではなく、出てくる順です。

**Colab**  
ブラウザで使う、借り物のPython実行環境。

**ノートブック**  
説明文とプログラムが交互に並んだファイル。拡張子は `.ipynb`。

**セル**  
ノートの1ブロック。文章用とプログラム用がある。

**ランタイム**  
今つながっている借り物パソコンのこと。切ると中のファイルは消える。

**GPU**  
AI向きの計算機。

**VRAM**  
GPUの作業机。単位はGB。

**L4 / T4 / A100 / H100 / G4**  
GPUの種類の名前。机の広さと速さと料金（回数券の減り方）が違う。

**CU（コンピューティングユニット）**  
月ごとの回数券。GPUを使うと減る。

**Google AI Pro**  
Gemini などが付く月額プラン。2026年9月から Colab の有料相当も付く。

**Colab Pro**  
Colabだけを買う古い呼び方のプラン。今の特典と似ているが、契約の入口が違う。

**OSSモデル**  
重みが公開されていて、自分の機械で動かせるAI。

**重み（ウェイト）**  
モデルの中身。巨大な数字の表。

**Hugging Face**  
モデルの倉庫。

**推論**  
できあがったモデルに質問して、返事をもらうこと。

**学習 / ファインチューン**  
モデルに追加で教えること。全部を作り直すわけではないことが多い。

**LoRA / QLoRA**  
薄い追加部品だけを学習する方法。QLoRAは、本体を圧縮したまま部品を付ける方法。

**量子化**  
重みを圧縮すること。

**OOM**  
机が足りなくて落ちること。out of memory。

**トークン**  
AIが扱う言葉の破片。文字そのものではない。

**コンテキスト**  
一度に覚えられる会話の長さ。長いほど机を食う。

**GGUF**  
持ち運び向きのモデルファイル形式。Ollama などでよく使う。

**Ollama**  
家のPCでモデルを動かすためのソフトの一つ。

**vLLM**
会話を速く、同時にたくさんさばくための推論専用のソフト。[実験03](results/03_vllm_speedup.md) で transformers より 2.2 倍速かった。

**AWQ**
量子化の方式の一つ。量子化済みの重みを配っておき、vLLM などで速く動かす。

**MoE（Mixture of Experts）**
中に「専門家」をたくさん持ち、1トークンごとに一部だけを使う型のモデル。全体は大きいが計算は軽い。例: Gemma 4 26B-A4B（全体 26B、動くのは約 4B）。

**KV キャッシュ**
会話の途中経過を覚えておくための GPU メモリ。長い会話や同時にたくさんの会話をするほど必要になる。

**thinking（思考モード）**
答える前に、モデルが自分用のメモ（思考）を書いてから答えるモード。難しい問題に強いが、遅くなる。[実験08](results/08_thinking_on_off.md)
